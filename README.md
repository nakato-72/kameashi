# カメアシ

カメラマンは、あなた。カメアシは、撮影をサポート。

撮りたい写真を探し、「どう撮るか」を視覚的に理解できる撮影アシスタントのブラウザ版MVPです。

## 公開

GitHub Pages で公開しています。

https://nakato-72.github.io/kameashi/

メンテナンス手順は `MAINTENANCE.md` を見てください。

## 開発

```bash
npm install
npm run dev
```

ブラウザで http://localhost:5173 を開きます。スマートフォン表示を前提としているため、開発者ツールのモバイル表示、または同じWi-Fi内の端末からアクセスして確認してください。

## ビルド

```bash
npm run build
npm run preview
```
